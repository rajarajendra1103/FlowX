# `create-flowx-app` — FlowX Generator CLI ⚡

Zero-config scaffolding tool for creating standalone FlowX applications with static CDN scripting and server-rendered HTML templates.

---

## 🚀 Quick Usage

```bash
npx create-flowx-app my-app
```

Then open `index.html` in any browser!
