# `@flowx/devtools` — FlowX Inspector DevTools ⚡

Visual Network & Custom Elements Inspector overlay for debugging FlowX applications in real time.

---

## 🚀 CDN Usage

```html
<script src="https://unpkg.com/@flowx/devtools/dist/index.global.js"></script>
```

Press **`Ctrl + Shift + F`** or click the glassmorphic widget floating in the bottom-right corner to open the network request timeline and Custom Elements inspector.
