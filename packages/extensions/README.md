# `@flowx/extensions` — WebSocket, SSE & Validation Plugins ⚡

Real-time streaming and client-side validation extensions for FlowX.

---

## 🚀 CDN Usage

```html
<!-- WebSocket Plugin -->
<script src="https://unpkg.com/@flowx/extensions/dist/websockets.global.js"></script>

<!-- SSE Plugin -->
<script src="https://unpkg.com/@flowx/extensions/dist/sse.global.js"></script>
```
